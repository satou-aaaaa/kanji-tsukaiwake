# 漢字つかいわけ（kanji-tsukaiwake）

同じ読みで漢字がちがうことば（会う・合う・遭う、計る・測る・量る、勧める・薦める など）を、短い文の中で使い分ける1日5問の学習ゲーム。正解したら「この字は、どんな意味？」も、同じ読みの字の意味から選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/kanji-tsukaiwake/>

- 中身は、文化審議会国語分科会「「異字同訓」の漢字の使い分け例（報告）」（平成26年2月21日。文化庁 <https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/ijidokun_140221.pdf>）の用例と意味の書き方だけです（2026-11-17 に読みました）。
- 報告は使い分けの目安です。「日が昇る／上る」のように、報告がどちらも使えるとする用例は問題にしていません。
- このゲームは漢字の使い分けを知る練習です。公式の情報の代わりではありません。使い分けは文化庁の報告で確かめてください。
